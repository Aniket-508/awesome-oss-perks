description: Просмотр и изменение настроек анонимного сбора данных об использовании CLI.
---

## Использование

```
ossperks telemetry [status|enable|disable]
```

Запуск `ossperks telemetry` без подкоманды выводит текущий статус.

## Подкоманды

| Подкоманда | Описание                                                  |
| ---------- | --------------------------------------------------------- |
| `status`   | Показать, включена ли телеметрия и откуда взята настройка |
| `enable`   | Включить телеметрию                                       |
| `disable`  | Выключить телеметрию                                      |

## Что собирается

Телеметрия **включена по умолчанию**. При первой отправке события выводится уведомление.

| Поле                                              | Пример             |
| ------------------------------------------------- | ------------------ |
| Имя команды                                       | `cli:check`        |
| Версия CLI                                        | `0.4.0`            |
| Операционная система, архитектура                 | `linux`, `arm64`   |
| Версия Node                                       | `v22.20.0`         |
| Выполняется ли запуск в CI                        | `true`             |
| Анонимный идентификатор: `sha256(host:user)[:16]` | `9f1c2ab4d0e3f871` |

Для неудачных команд дополнительно отправляются имя команды, сообщение об ошибке и трассировка стека.

**Никогда не собирается:** имена или URL репозиториев, пути к файлам, токены, содержимое проекта, а также имя вашего хоста и имя пользователя в открытом виде.

События отправляются в [PostHog](https://posthog.com) по адресу `https://us.i.posthog.com`. Сбои доставки игнорируются без уведомлений — телеметрия никогда не выводит ошибки в терминал и никогда не задерживает выполнение команды.

## Отказ от сбора данных

Достаточно любого из этих способов:

```bash
# Persisted to ~/.ossperks/telemetry.json
ossperks telemetry disable

# Per-shell, also honoured by other developer tools
export DO_NOT_TRACK=1
export DISABLE_TELEMETRY=1
```

Переменные окружения имеют приоритет над файлом конфигурации, поэтому оболочка с `DO_NOT_TRACK=1` остаётся отключённой от сбора данных даже после `ossperks telemetry enable`.

## Вывод

```
Telemetry
─────────

  Status  disabled
  Config  /home/you/.ossperks/telemetry.json

  Anonymous usage data: command name, CLI version, OS, arch, Node version,
  and whether the run is in CI. No repo names, paths, or tokens are sent.
```
