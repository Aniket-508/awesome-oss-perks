- **提供商**：Tembo
- **类别**：ai
- **网站**：[https://www.tembo.io/oss](https://www.tembo.io/oss)

## 福利

- **完整功能访问**：完全访问所有 Tembo 功能，包括 AI 代理、自动化和集成
- **无限贡献者**：无限贡献者，无需额外费用
- **优先支持**：来自我们团队的优先支持
- **开源免费**：无附加条件 - 只要您的项目保持开源，就可以继续免费使用 Tembo
- **GitHub 集成**：与您的仓库和工作流程无缝集成 GitHub

## 资格要求

- 项目必须在 GitHub 或 GitLab 上公开可用
- 采用 MIT、Apache 2.0 或类似的 OSI 批准许可证
- 必须是非商业性质（不得用于营收项目）
- 申请人必须是仓库的所有者或维护者
- 项目应有活跃的开发和社区参与

## 如何申请

1. 通过 Tembo OSS 计划申请页面提交申请。
2. Tembo 审核申请的资格。
