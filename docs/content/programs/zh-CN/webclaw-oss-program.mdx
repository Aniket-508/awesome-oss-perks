- **提供商**：Webclaw
- **类别**：devtools
- **网站**：[https://webclaw.io/oss](https://webclaw.io/oss)

## 权益

- **每月 100,000 积分**：与 Growth 计划相同的月度积分，免费提供，只要您的项目保持活跃。爬取、抓取、搜索和提取数据，无需担心用量限制。
- **我们会推广您的项目**：您的 logo 和仓库链接将展示在 webclaw.io 和我们的社交媒体渠道上，面向正在寻找您所构建工具的开发者。
- **优先支持**：在 Discord 上与团队直接联系。来自开源构建者的 bug 反馈和功能请求将获得优先处理。
- **自动续期**：只要您的项目保持活跃且集成文档保持更新，该资助每月自动续期，无需重新申请。

## 资格要求

- 公开且开源
在 OSI 批准的许可证下的公开仓库。任何语言、任何框架均可。
- 真实的 webclaw 集成
您的工具将 webclaw 作为其功能的一部分调用：加载器、MCP 服务器、模板、操作或 CLI。
- 积极维护
近期有提交记录、完整的 README 文档、有人维护。我们资助活跃的项目。
- 为他人使用而构建
最符合条件的项目会将 webclaw 展示给您自己的用户：人们可以安装、克隆或运行的工具。
