- **提供商**：Neon
- **类别**：开发工具
- **网站**：[https://neon.com/programs/open-source](https://neon.com/programs/open-source)

## 福利

- **平台积分**：符合条件的开源软件每年可获得高达 5,000 美元的平台积分。
- **现金推荐计划**：通过 GitHub Sponsorships，您推荐的每位开发者成为 Neon 客户后，您将获得 20 美元奖励。
- **营销支持**：通过博客文章、社交媒体、案例研究和联合营销活动，获得推广支持，将您的项目推广给 Neon 超过 100 万的开发者社区。

## 资格要求

- 您的项目必须是开源的，并在公认的开源许可证下公开可用。
- 开发者应能够自行托管该软件。
- 使用 Postgres 的开源软件最为适合。
- 提供文档、CLI 工具和代码示例，教用户如何使用您的软件和 Neon 进行构建。

## 如何申请

1. 通过联系表单与我们取得联系。
2. 等待回复，通常在 1-3 个工作日内。
