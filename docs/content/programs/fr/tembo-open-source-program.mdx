- **Fournisseur** : Tembo
- **Catégorie** : ia
- **Site web** : [https://www.tembo.io/oss](https://www.tembo.io/oss)

## Avantages

- **Accès complet aux fonctionnalités** : Accès complet à toutes les fonctionnalités Tembo, y compris les agents IA, les automatisations et les intégrations
- **Contributeurs illimités** : Nombre illimité de contributeurs sans frais supplémentaires
- **Support prioritaire** : Support prioritaire de notre équipe
- **Gratuit pour l'Open Source** : Sans conditions - continuez à utiliser Tembo gratuitement tant que votre projet reste open source
- **Intégration GitHub** : Intégration transparente avec vos dépôts et flux de travail GitHub

## Éligibilité

- Le projet doit être publiquement accessible sur GitHub ou GitLab
- Sous licence MIT, Apache 2.0 ou similaire approuvée par l'OSI
- Doit être non commercial (pas de projets générant des revenus)
- Le candidat doit être propriétaire ou mainteneur du dépôt
- Le projet doit avoir un développement actif et un engagement communautaire

## Comment postuler

1. Postulez via la page de candidature du Programme OSS Tembo.
2. Tembo examine la candidature pour vérifier l'éligibilité.
