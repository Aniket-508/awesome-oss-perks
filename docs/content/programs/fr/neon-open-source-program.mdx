## Avantages

- **Crédits de plateforme** : Les logiciels open source éligibles reçoivent jusqu'à 5 000 $ de crédits de plateforme par an.
- **Programme de parrainage rémunéré** : Recevez 20 $ via GitHub Sponsorships pour chaque développeur qui découvre Neon grâce à votre travail et devient client.
- **Soutien marketing** : Assistance promotionnelle pour élargir la visibilité de votre projet auprès de la communauté de plus d'un million de développeurs de Neon, via des articles de blog, les réseaux sociaux, des études de cas et des initiatives de co-marketing.

## Éligibilité

- Votre travail doit être open source et accessible publiquement sous une licence open source reconnue.
- Les développeurs doivent pouvoir auto-héberger le logiciel.
- Les logiciels open source qui utilisent Postgres sont particulièrement adaptés.
- Fournissez de la documentation, des outils CLI et des exemples de code qui enseignent aux utilisateurs comment développer avec votre logiciel et Neon.

## Comment postuler

1. Prenez contact via le formulaire de contact.
2. Attendez une réponse, généralement sous 1 à 3 jours ouvrables.
