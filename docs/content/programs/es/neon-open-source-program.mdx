- **Proveedor**: Neon
- **Categoría**: devtools
- **Sitio web**: [https://neon.com/programs/open-source](https://neon.com/programs/open-source)

## Beneficios

- **Créditos de Plataforma**: El software de código abierto elegible recibe hasta $5,000 en créditos de plataforma anualmente.
- **Programa de Referencias en Efectivo**: Recibe $20 a través de GitHub Sponsorships por cada desarrollador que descubra Neon gracias a tu trabajo y se convierta en cliente.
- **Apoyo de Marketing**: Soporte promocional para ampliar la visibilidad de tu proyecto ante la comunidad de más de 1 millón de desarrolladores de Neon mediante publicaciones de blog, redes sociales, casos de estudio e iniciativas de co-marketing.

## Elegibilidad

- Tu trabajo debe ser de código abierto y estar disponible públicamente bajo una licencia de código abierto reconocida.
- Los desarrolladores deben poder autoalojar el software.
- El software de código abierto que utiliza Postgres es ideal.
- Proporciona documentación, herramientas CLI y ejemplos de código que enseñen a los usuarios cómo construir con tu software y Neon.

## Cómo aplicar

1. Ponte en contacto a través del formulario de contacto.
2. Espera una respuesta, generalmente en 1-3 días hábiles.
