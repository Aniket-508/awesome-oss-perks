- **Proveedor**: Tembo
- **Categoría**: ia
- **Sitio web**: [https://www.tembo.io/oss](https://www.tembo.io/oss)

## Ventajas

- **Acceso Completo a Funciones**: Acceso completo a todas las funciones de Tembo, incluyendo agentes de IA, automatizaciones e integraciones
- **Colaboradores Ilimitados**: Colaboradores ilimitados sin costo adicional
- **Soporte Prioritario**: Soporte prioritario de nuestro equipo
- **Gratis para Código Abierto**: Sin compromisos - sigue usando Tembo gratis mientras tu proyecto siga siendo de código abierto
- **Integración con GitHub**: Integración perfecta con GitHub para tus repositorios y flujos de trabajo

## Elegibilidad

- El proyecto debe estar disponible públicamente en GitHub o GitLab
- Licenciado bajo MIT, Apache 2.0 o una licencia similar aprobada por OSI
- Debe ser no comercial (sin proyectos que generen ingresos)
- El solicitante debe ser propietario o mantenedor del repositorio
- El proyecto debe tener desarrollo activo y participación de la comunidad

## Cómo postular

1. Postula a través de la página de solicitud del Programa OSS de Tembo.
2. Tembo revisa la solicitud para verificar la elegibilidad.
