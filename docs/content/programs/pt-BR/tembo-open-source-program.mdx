- **Provedor**: Tembo
- **Categoria**: ia
- **Site**: [https://www.tembo.io/oss](https://www.tembo.io/oss)

## Benefícios

- **Acesso Completo aos Recursos**: Acesso total a todos os recursos do Tembo, incluindo agentes de IA, automações e integrações
- **Colaboradores Ilimitados**: Colaboradores ilimitados sem custo adicional
- **Suporte Prioritário**: Suporte prioritário da nossa equipe
- **Gratuito para Open Source**: Sem compromissos - continue usando o Tembo gratuitamente enquanto seu projeto permanecer open source
- **Integração com GitHub**: Integração perfeita com seus repositórios e fluxos de trabalho do GitHub

## Elegibilidade

- O projeto deve estar disponível publicamente no GitHub ou GitLab
- Licenciado sob MIT, Apache 2.0 ou licença similar aprovada pela OSI
- Deve ser não comercial (sem projetos geradores de receita)
- O solicitante deve ser proprietário ou mantenedor do repositório
- O projeto deve ter desenvolvimento ativo e engajamento da comunidade

## Como se candidatar

1. Candidate-se através da página de inscrição do Programa OSS do Tembo.
2. O Tembo avalia a inscrição quanto à elegibilidade.
