- **Site**: [https://neon.com/programs/open-source](https://neon.com/programs/open-source)

## Benefícios

- **Créditos da Plataforma**: Softwares de código aberto elegíveis recebem até US$ 5.000 em créditos da plataforma anualmente.
- **Programa de Indicação em Dinheiro**: Receba US$ 20 via GitHub Sponsorships para cada desenvolvedor que descobrir a Neon através do seu trabalho e se tornar um cliente.
- **Suporte de Marketing**: Suporte promocional para expandir a visibilidade do seu projeto para a comunidade de mais de 1 milhão de desenvolvedores da Neon através de posts de blog, redes sociais, estudos de caso e iniciativas de co-marketing.

## Elegibilidade

- Seu trabalho deve ser de código aberto e estar publicamente disponível sob uma licença de código aberto reconhecida.
- Os desenvolvedores devem poder hospedar o software por conta própria.
- Softwares de código aberto que usam Postgres são ideais.
- Forneça documentação, ferramentas CLI e exemplos de código que ensinem os usuários a construir com seu software e a Neon.

## Como se candidatar

1. Entre em contato através do formulário de contato.
2. Aguarde uma resposta, normalmente dentro de 1 a 3 dias úteis.
