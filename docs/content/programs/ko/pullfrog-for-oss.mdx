- **제공업체**: Pullfrog
- **카테고리**: ai
- **웹사이트**: [https://pullfrog.com/for-oss](https://pullfrog.com/for-oss)

## 혜택

- **무료 모델 사용**: Kimi K2.6 무제한 사용.

## 자격 요건

- 1,000개 이상의 스타를 보유한 GitHub 저장소를 유지해야 합니다.

## 신청 방법

1. GitHub 저장소에 1,000개 이상의 스타가 있는 경우 제공된 링크를 통해 신청하세요.
