- **제공업체**: Webclaw
- **카테고리**: devtools
- **웹사이트**: [https://webclaw.io/oss](https://webclaw.io/oss)

## 혜택

- **월 100,000 크레딧**: 프로젝트가 활성 상태를 유지하는 동안 Growth 플랜과 동일한 월간 크레딧을 무료로 제공합니다. 사용량 걱정 없이 스크래핑, 크롤링, 검색 및 추출 작업을 수행하세요.
- **프로젝트 홍보**: webclaw.io와 소셜 채널에 여러분의 로고와 저장소 링크를 게재하여, 여러분이 만든 프로젝트를 찾고 있는 개발자들에게 노출합니다.
- **우선 지원**: Discord를 통해 팀과 직접 소통할 수 있습니다. OSS 제작자의 버그 신고와 기능 요청은 우선 처리됩니다.
- **자동 갱신**: 프로젝트가 활성 상태를 유지하고 통합이 문서화되어 있는 한 매월 자동으로 갱신됩니다. 재신청이 필요 없습니다.

## 자격 요건

- 공개 및 오픈 소스
OSI 승인 라이선스 하의 공개 저장소. 모든 언어, 모든 프레임워크 가능.
- 실제 webclaw 통합
여러분의 도구가 작동의 일부로 webclaw를 호출해야 합니다: 로더, MCP 서버, 템플릿, 액션, CLI 등.
- 활발하게 유지 관리됨
최근 커밋, 제대로 작성된 README, 관리자 존재. 우리는 살아있는 프로젝트를 지원합니다.
- 다른 사람들이 사용할 수 있도록 제작됨
가장 적합한 경우는 여러분의 사용자에게 webclaw를 제공하는 것입니다: 사람들이 설치하거나, 클론하거나, 실행할 수 있는 것.
