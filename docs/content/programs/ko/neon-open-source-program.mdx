- **제공업체**: Neon
- **카테고리**: devtools
- **웹사이트**: [https://neon.com/programs/open-source](https://neon.com/programs/open-source)

## 혜택

- **플랫폼 크레딧**: 적격 오픈소스 소프트웨어는 연간 최대 $5,000의 플랫폼 크레딧을 받을 수 있습니다.
- **현금 추천 프로그램**: 귀하의 작업을 통해 Neon을 알게 되고 고객이 된 모든 개발자에 대해 GitHub Sponsorships를 통해 $20를 받으실 수 있습니다.
- **마케팅 지원**: 블로그 게시물, 소셜 미디어, 사례 연구 및 공동 마케팅 활동을 통해 Neon의 100만 명 이상의 개발자 커뮤니티에 프로젝트의 가시성을 확대하기 위한 홍보 지원을 제공합니다.

## 자격 요건

- 귀하의 작업은 인정된 오픈소스 라이선스에 따라 오픈소스이며 공개적으로 이용 가능해야 합니다.
- 개발자가 소프트웨어를 자체 호스팅할 수 있어야 합니다.
- Postgres를 사용하는 오픈소스 소프트웨어가 이상적입니다.
- 사용자가 귀하의 소프트웨어와 Neon을 사용하여 빌드하는 방법을 가르치는 문서, CLI 도구 및 코드 예제를 제공해야 합니다.
