- **제공자**: Tembo
- **카테고리**: ai
- **웹사이트**: [https://www.tembo.io/oss](https://www.tembo.io/oss)

## 혜택

- **모든 기능 접근**: AI 에이전트, 자동화 및 통합을 포함한 모든 Tembo 기능에 대한 전체 액세스
- **무제한 기여자**: 추가 비용 없이 무제한 기여자 지원
- **우선 지원**: 팀의 우선 지원
- **오픈 소스 무료 제공**: 프로젝트가 오픈 소스로 유지되는 한 무료로 Tembo를 계속 사용할 수 있습니다
- **GitHub 통합**: 저장소 및 워크플로와의 원활한 GitHub 통합

## 자격 요건

- 프로젝트가 GitHub 또는 GitLab에서 공개적으로 이용 가능해야 합니다
- MIT, Apache 2.0 또는 이와 유사한 OSI 승인 라이선스로 라이선스되어야 합니다
- 비상업적이어야 합니다(수익 창출 프로젝트 불가)
- 신청자는 저장소의 소유자 또는 관리자여야 합니다
- 프로젝트는 활발한 개발 및 커뮤니티 참여가 있어야 합니다

## 신청 방법

1. Tembo OSS 프로그램 신청 페이지를 통해 신청하세요.
2. Tembo가 자격 요건에 대한 신청을 검토합니다.
