- **Provider**: Tembo
- **Category**: ai
- **Website**: [https://www.tembo.io/oss](https://www.tembo.io/oss)

## Perks

- **Full Feature Access**: Full access to all Tembo features including AI agents, automations, and integrations
- **Unlimited Contributors**: Unlimited contributors at no additional cost
- **Priority Support**: Priority support from our team
- **Free for Open Source**: No strings attached - keep using Tembo for free as long as your project remains open source
- **GitHub Integration**: Seamless GitHub integration with your repositories and workflows

## Eligibility

- Project must be publicly available on GitHub or GitLab
- Licensed under MIT, Apache 2.0, or similar OSI-approved license
- Must be non-commercial (no revenue-generating projects)
- Applicant must be an owner or maintainer of the repository
- Project should have active development and community engagement

## How to apply

1. Apply through the Tembo OSS Program application page.
2. Tembo reviews the application for eligibility.
