- **Anbieter**: Tembo
- **Kategorie**: KI
- **Website**: [https://www.tembo.io/oss](https://www.tembo.io/oss)

## Vorteile

- **Vollständiger Funktionszugriff**: Vollständiger Zugriff auf alle Tembo-Funktionen einschließlich KI-Agenten, Automatisierungen und Integrationen
- **Unbegrenzte Mitwirkende**: Unbegrenzte Anzahl von Mitwirkenden ohne zusätzliche Kosten
- **Priority-Support**: Bevorzugter Support von unserem Team
- **Kostenlos für Open Source**: Keine Bedingungen – nutzen Sie Tembo weiterhin kostenlos, solange Ihr Projekt Open Source bleibt
- **GitHub-Integration**: Nahtlose GitHub-Integration mit Ihren Repositories und Workflows

## Voraussetzungen

- Das Projekt muss öffentlich auf GitHub oder GitLab verfügbar sein
- Lizenziert unter MIT, Apache 2.0 oder einer ähnlichen OSI-zugelassenen Lizenz
- Muss nicht-kommerziell sein (keine umsatzgenerierenden Projekte)
- Der Antragsteller muss Eigentümer oder Maintainer des Repositorys sein
- Das Projekt sollte aktive Entwicklung und Community-Engagement aufweisen

## So bewerben Sie sich

1. Bewerben Sie sich über die Bewerbungsseite des Tembo OSS-Programms.
2. Tembo prüft die Bewerbung auf Eignung.
