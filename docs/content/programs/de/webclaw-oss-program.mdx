- **Kategorie**: devtools
- **Website**: [https://webclaw.io/oss](https://webclaw.io/oss)

## Vorteile

- **100.000 Credits / Monat**: Die gleichen monatlichen Credits wie im Growth-Plan, kostenlos, solange Ihr Projekt aktiv bleibt. Scrapen, Crawlen, Suchen und Extrahieren, ohne auf die Uhr zu schauen.
- **Wir präsentieren Ihr Projekt**: Ihr Logo und Repo-Link auf webclaw.io und auf unseren Social-Media-Kanälen, vor Entwicklern, die genau nach dem suchen, was Sie gebaut haben.
- **Prioritätssupport**: Eine direkte Verbindung zum Team auf Discord. Bugs und Feature-Requests von OSS-Entwicklern werden bevorzugt behandelt.
- **Es verlängert sich automatisch**: Das Stipendium wird jeden Monat erneuert, solange Ihr Projekt aktiv bleibt und die Integration dokumentiert ist. Keine erneute Bewerbung erforderlich.

## Voraussetzungen

- Öffentlich und Open Source
Ein öffentliches Repository unter einer OSI-zugelassenen Lizenz. Jede Sprache, jedes Framework.
- Eine echte webclaw-Integration
Ihr Tool ruft webclaw als Teil seiner Funktionalität auf: ein Loader, ein MCP-Server, ein Template, eine Action, ein CLI.
- Aktiv gepflegt
Aktuelle Commits, eine aussagekräftige README, jemand zu Hause. Wir fördern lebendige Projekte.
- Für andere Nutzer entwickelt
Am besten geeignet sind Projekte, die webclaw Ihren eigenen Nutzern zugänglich machen: etwas, das Leute installieren, klonen oder ausführen.
