- **Категория**: devtools
- **Веб-сайт**: [https://neon.com/programs/open-source](https://neon.com/programs/open-source)

## Преимущества

- **Кредиты платформы**: Подходящее программное обеспечение с открытым исходным кодом получает до $5 000 в виде кредитов платформы ежегодно.
- **Денежная реферальная программа**: Получайте $20 через GitHub Sponsorships за каждого разработчика, который узнал о Neon благодаря вашей работе и стал клиентом.
- **Маркетинговая поддержка**: Продвижение для расширения видимости вашего проекта среди более чем 1 млн разработчиков сообщества Neon через статьи в блогах, социальные сети, кейсы и совместные маркетинговые инициативы.

## Требования

- Ваша работа должна быть с открытым исходным кодом и общедоступна под признанной лицензией open source.
- Разработчики должны иметь возможность самостоятельно развернуть программное обеспечение.
- Программное обеспечение с открытым исходным кодом, использующее Postgres, идеально подходит.
- Предоставьте документацию, инструменты CLI и примеры кода, которые научат пользователей, как создавать приложения с вашим ПО и Neon.

## Как подать заявку

1. Свяжитесь с нами через контактную форму.
2. Дождитесь ответа, обычно в течение 1-3 рабочих дней.
