- **プロバイダー**: Webclaw
- **カテゴリー**: devtools
- **ウェブサイト**: [https://webclaw.io/oss](https://webclaw.io/oss)

## 特典

- **月間100,000クレジット**: Growthプランと同じ月間クレジットを、プロジェクトがアクティブである限り無料で利用できます。メーターを気にすることなく、スクレイピング、クロール、検索、抽出が可能です。
- **プロジェクトの紹介**: webclaw.ioと当社のソーシャルチャネルに、あなたのロゴとリポジトリリンクを掲載し、まさにあなたが構築したものを探している開発者の目に留まるようにします。
- **優先サポート**: Discordでチームと直接つながることができます。OSSビルダーからのバグ報告や機能リクエストは優先的に対応されます。
- **自動更新**: プロジェクトがアクティブで統合のドキュメントが維持されている限り、助成金は毎月自動更新されます。再申請は不要です。

## 応募資格

- 公開されたオープンソースプロジェクト
OSI承認ライセンスの下で公開されているリポジトリ。言語やフレームワークは問いません。
- 実際のwebclaw統合
あなたのツールが機能の一部としてwebclawを呼び出していること:ローダー、MCPサーバー、テンプレート、アクション、CLIなど。
- 積極的にメンテナンスされている
最近のコミット、充実したREADME、管理者が存在すること。私たちは活発なプロジェクトを支援します。
- 他の人が使用するために構築されている
最も適しているのは、あなた自身のユーザーの前にwebclawを置くこと:人々がインストール、クローン、または実行できるものです。
