- **プロバイダー**: Tembo
- **カテゴリー**: ai
- **ウェブサイト**: [https://www.tembo.io/oss](https://www.tembo.io/oss)

## 特典

- **全機能へのアクセス**: AIエージェント、自動化、統合を含むTemboの全機能への完全なアクセス
- **無制限のコントリビューター**: 追加料金なしで無制限のコントリビューター
- **優先サポート**: チームによる優先サポート
- **オープンソースは無料**: 条件なし - プロジェクトがオープンソースである限り、Temboを無料で使い続けられます
- **GitHub統合**: リポジトリとワークフローとのシームレスなGitHub統合

## 対象条件

- プロジェクトはGitHubまたはGitLabで公開されている必要があります
- MIT、Apache 2.0、または同様のOSI承認ライセンスで提供されていること
- 非商用であること(収益を生み出すプロジェクトは対象外)
- 申請者はリポジトリのオーナーまたはメンテナーであること
- プロジェクトは活発な開発とコミュニティエンゲージメントがあること

## 申請方法

1. Tembo OSSプログラム申請ページから申請してください。
2. Temboが適格性を審査します。
