- **プロバイダー**: Neon
- **カテゴリー**: devtools
- **ウェブサイト**: [https://neon.com/programs/open-source](https://neon.com/programs/open-source)

## 特典

- **プラットフォームクレジット**: 対象となるオープンソースソフトウェアには、年間最大5,000ドル相当のプラットフォームクレジットが提供されます。
- **現金紹介プログラム**: あなたの作品を通じてNeonを知り、顧客となった開発者1人につき、GitHub Sponsorships経由で20ドルを受け取ることができます。
- **マーケティングサポート**: ブログ投稿、ソーシャルメディア、ケーススタディ、共同マーケティング施策を通じて、Neonの100万人以上の開発者コミュニティにプロジェクトの認知度を拡大するためのプロモーションサポートを提供します。

## 応募資格

- あなたの作品はオープンソースであり、認められたオープンソースライセンスの下で公開されている必要があります。
- 開発者がソフトウェアをセルフホストできる必要があります。
- Postgresを使用するオープンソースソフトウェアが理想的です。
- ユーザーがあなたのソフトウェアとNeonを使って構築する方法を教えるドキュメント、CLIツール、コード例を提供してください。

## 応募方法

1. お問い合わせフォームからご連絡ください。
2. 通常1〜3営業日以内に返信をお待ちください。
